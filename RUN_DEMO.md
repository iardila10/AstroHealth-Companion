# Run the Local Demo

This guide starts the AstroHealth Companion frontend and backend locally and runs the synthetic health-data simulator.

The simulator does not require Render, physical sensors, or an external API service. An internet connection is needed initially to install the project dependencies. Once installed, the demo runs on the same computer and does not require internet access.

All measurements generated by the simulator are synthetic. They are for demonstration purposes only and must not be used for medical decisions.

## Prerequisites

- Git
- Python 3.12
- Node.js and npm

## Get the Project

If you have not already cloned the repository:

```bash
git clone https://github.com/iardila10/AstroHealth-Companion.git
cd AstroHealth-Companion
```

Run the following commands from the repository root unless a step says otherwise.

## Start the Backend

Open a terminal, change to the `backend` directory, and create the Python virtual environment.

### Windows (PowerShell)

```powershell
cd backend
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

### macOS or Linux

```bash
cd backend
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

Keep this terminal open. The API listens at `http://localhost:8000`. Verify that it is running by opening `http://localhost:8000/health`; a JSON response with `"status": "ok"` indicates that the API is ready.

In the default development configuration, the backend creates the SQLite tables automatically. The local database is stored at `backend/astrohealth.db`.

## Start the Frontend

Open a second terminal at the repository root (not inside `backend`) and run:

```bash
npm ci
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`. By default, the frontend connects to the API at `http://localhost:8000`.

## Run the Simulator

1. In the dashboard, select **＋ Tripulante**, enter a name and role, and select **Registrar**.
2. Select a simulator profile: **Normal**, **Atención**, or **Crítico**.
3. Select **Iniciar demo**. The backend generates and evaluates a synthetic measurement approximately every 2.5 seconds.
4. Select **Pausar demo** to stop the simulator.

The dashboard updates with the simulated evaluations, alerts, and recommendations. The simulator controls are shown when the frontend is running in development mode.

## Troubleshooting

- **The dashboard cannot connect to the API:** Make sure the backend terminal is still running and that `http://localhost:8000/health` responds successfully.
- **The simulator control is disabled:** Register an astronaut first; the simulator requires a selected astronaut.
- **The simulator endpoint is unavailable:** The demo endpoint is disabled when the backend `ENVIRONMENT` setting is `production`. The default local configuration is `development`.
- **The frontend is opened at a different address:** The backend's default CORS configuration allows `http://localhost:5173` and `http://127.0.0.1:5173`. Use the default Vite address or configure `CORS_ORIGINS` for the frontend origin.

This local simulator demonstrates the app's evaluation workflow. It does not implement a mission communications link or transmit data to an operational ground system.
